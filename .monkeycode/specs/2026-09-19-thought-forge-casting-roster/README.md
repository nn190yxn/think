# 思想熔炉 · 点将与大师名册（任务文件夹）

作者: Monkeycode

## 项目简介

这是「思想熔炉」桌面应用的一个规格与交付文件夹，对应 P20 至 P28 的任务范围：把大师名册从 6 位扩到 20 位，让会诊前能点将、能看到每位大师在六题（道法术气器势）上的积累，并把可用性与清理收口到可交付状态。

## 使用方式

1. 先看交付单：`DELIVERY.md`（交付了什么、怎么上手、哪些验证过、哪些没验证）。
2. 再看任务现状：`tasklist.md`（P20 至 P28 的勾选与实测备注）。
3. 名册与统计：`roster-plan.md`（规划、执行结果、按题统计）。
4. 每位大师的蒸馏过程稿在 `distill/<大师 id>/`；成品在仓库根 `seed-packs/<大师 id>/`。

## 产出文件

- `seed-packs/` 下 20 个种子大师包（每个含 `master.json` 与 `corpus/notes.md`）。
- `distill/<大师 id>/` 下每位九份过程稿（总览、候选池、三重验证、淘汰记录、选角用例、出处记录）。

## 关键依赖

- 前端：React 19 + Vite + Vitest（`pnpm gate:front`）。
- 内核：Rust crate `thought-forge-core`（`pnpm gate:core`）。
- 桌面壳：Rust crate `thought-forge-desktop`（`pnpm gate:shell`）。
- 内容流程：仓颉蒸馏流程（分阶段提取 → 三重验证 → 留淘汰记录 → 六题收口）。
