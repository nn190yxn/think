## 二、可确认为其理论核心的

- 五力模型：现有竞争者之间的竞争、潜在进入者的威胁、替代品的威胁、供应商的议价能力、客户的议价能力。
- 三大通用战略：总成本领先、差异化、专一聚焦（缝隙市场）。
- 三种战略要求的条件不一致，**相继或同时采用三个战略注定失败**；处在中间状态（stuck in the middle）最为不利。
- 价值链：基本活动（内部后勤、生产作业、外部后勤、市场与销售、服务）＋支持活动（采购、技术开发、人力资源管理、企业基础设施），九项活动构成价值链。
- 钻石体系：国家竞争优势的四个要素框架（《国家竞争优势》）。
- 1980 年《竞争战略》出版后不断再版，改变了 CEO 的战略思维。

## 三、标为「转述」的

- 「竞争的本质不是打败同行，是构建自己的盈利壁垒」——这是解读文章对其思想的通俗概括，非其原句。
- 「要么极致便宜，要么极致特别，要么极致细分，最怕平庸从众」——同上，属转述性总结。
- 价值链理论的后续发展（分解与整合、虚拟经营）是该理论的延伸，不是他本人的主张。

## 四、核验记录

2026-09-21：条目经全网检索核对，来源包括两篇中文核心期刊论文摘要（维普）、两个百科条目与一篇通俗解读。

**批评同时留存**（写入边界与盲点）：
1. 五力模型被批**过于简单化**，用以分析行业吸引力时容易失真。
2. 三大通用战略在**逻辑上缺乏严密性**（期刊批评）。
3. 把企业视为「黑箱」，假定行业内企业**同质**，忽视企业间能力差异。
4. 理论假设产生于**相对结构化的市场环境**，与快速变化的实际环境不完全一致。
5. 定位学派整体被批评：强调行业稳定性、把战略制定过程过分正规化与通用化，**「偏爱呆在那儿，而不是去那儿」**。
6. 有专业解读提醒：五力对多数咨询专家只是参考框架，不考虑企业具体条件就套用，**结论会相当幼稚**。
