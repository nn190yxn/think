# 阶段 1：五路提取候选池（波特）

## 一、框架提取

| 候选 | 要点 | 出处 |
|---|---|---|
| 五力模型 | 现有竞争、进入者、替代品、供应商、客户 | 《竞争战略》1980 |
| 三大通用战略 | 总成本领先、差异化、专一聚焦 | 《竞争战略》 |
| 价值链 | 基本活动五项＋支持活动四项 | 《竞争优势》 |
| 钻石体系 | 国家竞争优势框架 | 《国家竞争优势》 |
| 卡在中间 | 三种战略都没占住的最差位置 | 《竞争战略》 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 结构决定利润 | 行业吸引力先于努力 |
| 竞争是建壁垒不是打对手 | 别陷进内卷 |
| 战略要选一个 | 三个都想要就会一个都占不住 |
| 定位不同，活动必须不同 | 战略要落到配置上 |
| 入局前先做行业体检 | 别盲目进场 |
| 框架是参考不是打分表 | 套用即幼稚 |

## 四、反例提取

| 候选 | 内容 |
|---|---|
| 卡在中间 | 不够便宜也不够特别 |
| 三战略同时上 | 条件冲突，注定失败 |
| 只看对手不看结构 | 陷入无限内卷 |
| 把五力当打分表 | 忽略具体条件，结论幼稚 |
| 行业衰退期硬扩产 | 结构已变，努力无效 |
