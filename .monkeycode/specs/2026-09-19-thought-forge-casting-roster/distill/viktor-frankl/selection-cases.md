# 阶段 4：选角测试用例（弗兰克尔）

## 一、该出手的

| 提问 | 期望选出的单元 |
|---|---|
| 家里出了不可逆的事，我知道改不了，但每天睡不着。 | 最后一种自由、意义的三个通道 |
| 工作体面、收入不低，但每天早上都不想睁眼。 | 意义的三个通道、生命在追问你 |
| 我一直在追幸福，越追越觉得空。 | 自我实现是副产品 |
| 每次上台前都紧张到发抖，怎么破。 | 矛盾意向法 |
| 我总在反复想自己的毛病，越想越糟。 | 去反省法 |

## 二、不该出手的（诱饵）

| 提问 | 为什么不该由他出手 |
|---|---|
| 我要不要跟这家公司谈涨薪。 | 属交易谈判，与意义框架无关 |
| 我的焦虑是不是该吃药。 | 医疗判断，必须由医生做；他提供的是意义与态度层面的辅助 |
| 今晚吃什么。 | 常识级问题 |

## 三、边界模糊的

| 提问 | 判定要点 |
|---|---|
| 这份工作压得我喘不过气，家人劝我忍。 | 先判断这份苦是否**不可避免**：可改变就先改变。若被用来劝人忍受本可改变的不公，属于误用，必须点明边界 |
| 我被人伤害了，是不是该"感谢这段经历"。 | 该触发「态度的价值」，但必须带上他的限制：苦难本身没有意义，别把它说成恩赐 |
| 我想找到人生的意义。 | 该出手，但要用「生命在追问你」把提问方向纠正过来，避免停在抽象讨论 |

## 四、跨同门混淆

| 提问 | 容易混淆 | 正确判断 |
|---|---|---|
| 我状态很差，什么都提不起劲。 | 存在之虚无（气）vs 意义的三个通道（法） | 先诊断是不是空虚（气），再补通道（法） |
| 我该忍受还是该反抗。 | 态度的价值（法）vs 最后一种自由（气） | 判断要不要接受选态度价值；判断"我还能选择什么"选最后一种自由 |
| 我一直想着自己的身体反应，越来越严重。 | 去反省法（术）vs 矛盾意向法（术） | 过度自我关注选去反省；预期性焦虑与发抖选矛盾意向 |
