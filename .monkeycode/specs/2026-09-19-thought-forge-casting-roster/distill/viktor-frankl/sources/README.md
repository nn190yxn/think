## 二、可确认为原话的

- "人所拥有的任何东西都可以被剥夺，唯独选择态度的自由除外。"
- "在忍受不可避免的苦难时采取某种态度，本身就是意义的实现。"
- "自我实现不能被直接追求，它只是人投身于比自己更大的事业时自然产生的副产品。"

## 三、属于他引用他人的（不可当他的原创）

- "知道为什么而活的人，几乎能忍受任何一种生存方式。"——出自**尼采**，弗兰克尔反复引用。
- "我只害怕一样——那就是配不上我所受的痛苦。"——出自**陀思妥耶夫斯基**，他在书中引用。

## 四、标为「转述」的

- 矛盾意向法与去反省法的具体操作（意义疗法的两种治疗技术）
- "存在之虚无"（existential vacuum）的定义
- 苦难不可追求，只在不可避免时才有意义；不必要的受苦不是英雄主义，而是受虐

## 五、核验记录

2026-09-21：条目经全网检索核对。三条途径的表述在图书馆书目与出版社推荐序之间一致（创造的价值、体验的价值、态度的价值）；两种治疗技术出自意义疗法专著的官方简介；引文部分明确区分了弗兰克尔本人原话与他对尼采、陀思妥耶夫斯基的引用。

**实证情况同时留存**：意义疗法的核心概念有后续量化支持（生活目的量表、600 余项研究），因此不把"无法验证"写进盲点；写入盲点的是"从极端处境提炼的框架迁移到普通生活的适用性"与"意义主观性可能被滥用"。
