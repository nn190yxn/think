| 候选 | 要点 | 出处 |
|---|---|---|
| 三条通道 | 创造的价值、体验的价值、态度的价值 | 《何为生命的意义》简介、推荐序 |
| 最后一种自由 | 选择回应方式的自由 | 《活出生命的意义》 |
| 存在之虚无 | 空心状态：不缺物质，缺值得奔赴的意义 | 全书理论部分 |
| 矛盾意向法 | 反向用力，用幽默打断预期焦虑 | 意义疗法专著简介 |
| 去反省法 | 注意力从自我转向任务与他人 | 意义疗法专著简介 |
| 自我实现是副产品 | 不能直接追求，投身更大事业时自然产生 | 推荐序 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 意义是具体的、个人的 | 不同的人、不同的时刻各不相同 |
| 苦难不可追求 | 不必要的受苦不是英雄主义，而是受虐 |
| 快乐不可直取 | 越追逐越远离，只在投入时降临 |
| 人是被生命追问的一方 | 用行动回答，而不是向生命索要答案 |
| 责任先于自由 | 自由必须落到"对什么负责"上 |
| 任何处境都留有回应空间 | 外部力量无法剥夺这一层 |
