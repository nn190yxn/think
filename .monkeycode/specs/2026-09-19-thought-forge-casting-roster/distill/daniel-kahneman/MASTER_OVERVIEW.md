# 阶段 0：卡尼曼的整体理解

## 一、主旨

**人在判断上不是偶尔出错，而是有规律地出错；看见这些规律，是把自己从错误里往外拉的第一步。**

卡尼曼不提供"如何更聪明"，他提供的是**错误地图**：大脑有两套处理方式（快与慢）、对得失的感受不对称（损失厌恶）、记忆会剪辑经历（峰终定律）、对未来的计划系统性乐观（规划谬误）、对同一件事的判断充满随机变异（噪声）。他的贡献在于把这些说成机制，而不是性格缺陷。

## 二、骨架

1. **双系统**：系统 1 快、自动、省力、易上当；系统 2 慢、费力、懒惰，常直接采纳系统 1 的结论。
2. **WYSIATI**：眼见即为事实——只用手上的信息构造连贯故事，忽略未知。
3. **得失不对称**：损失厌恶、参照点依赖、框架效应。
4. **两个自我**：经验自我在经历，记忆自我在总结；替我们做决定的常是记忆自我。
5. **过度自信的系统来源**：规划谬误、竞争忽视、有效性错觉。
6. **直觉的适用条件**：环境有规律、反馈及时时直觉可靠；否则不可靠。
7. **噪声与偏差**：错误 = 偏差（系统性方向错误）+ 噪声（本应一致的判断之间的随机差异）。

## 三、关键术语

| 术语 | 含义 |
|---|---|
| 系统 1 / 系统 2 | 快思考与慢思考的两种模式（描述性虚构） |
| WYSIATI | 眼见即为事实 |
| 前景理论 | 以参照点而非绝对值为核心的决策理论 |
| 损失厌恶 | 损失的痛约是等额收益快乐的 2—2.5 倍 |
| 锚定效应 | 先接触的数字会拽住后续判断 |
| 可得性 / 代表性 | 按"容易想起"和"像不像"来判断概率 |
| 峰终定律 | 记忆按峰值与结尾给经历打分 |
| 规划谬误 | 系统性低估时间、成本、风险 |
| 事前验尸 | 先假设已经失败，再回推原因 |
| 噪声 | 本应一致的判断之间出现的随机变异 |

## 四、批判与盲点

1. **双系统不是解剖结构**：原著自陈是"两个虚拟出来的角色"，把它当成大脑里的两个器官是误读。
2. **实验到现实的落差**：结论多来自受控实验，真实决策中变量难以隔离（我们的判断，非原著观点）。
3. **易被误用为宿命论**：知道偏差不等于不犯，"学过这本书"不能替代制度性防护。
4. **偏差清单容易变成新教条**：把每个决策都套一遍术语，反而拖慢该快的事。
5. **他的框架不回答"该往哪去"**：只诊断判断质量，不提供目标与价值判断。

## 五、可应用场景

重大决策前的前置检查、团队判断的降噪、对自己过度自信的校准、以及"这次该用直觉还是用公式"的分工判断。
