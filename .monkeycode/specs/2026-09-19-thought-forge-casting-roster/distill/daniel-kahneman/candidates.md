# 阶段 1：五路提取候选池（卡尼曼）

## 一、框架提取

| 候选 | 要点 | 出处 |
|---|---|---|
| 双系统 | 快与慢两套处理方式，系统 2 懒惰 | 《思考，快与慢》 |
| 前景理论 | 参照点、损失厌恶、框架效应 | 1979／1992 论文与书中第四部分 |
| 两个自我 | 经验自我与记忆自我，峰终定律 | 书中第五部分 |
| 噪声与偏差 | 错误 = 偏差 + 噪声，噪声更隐蔽 | 《噪声》 |
| 决策卫生 | 结构化、独立判断、取平均 | 清华对话、《噪声》 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 眼见即为事实 | 只用手上信息构造故事 |
| 直觉只在特定条件下可靠 | 规律性强、反馈及时 |
| 简单公式常胜过专家直觉 | 专家面谈不如打分表 |
| 损失厌恶约两倍 | 亏的痛苦大于赚的快乐 |
| 计划系统性乐观 | 规划谬误、竞争忽视 |
| 噪声不被察觉 | 像地下室漏水，不是可接受，而是没被发现 |

## 三、案例提取

| 候选 | 内容 | 出处 |
|---|---|---|
| 法官与骰子 | 先掷出 3 或 9 的法官，平均判 5 个月与 8 个月 | 书评引用书中实验 |
| 保险公司 50 位经理 | 同一案例保费差异超 50% | 清华对话（卡尼曼自述） |
| 冷水实验 | 80% 的人选更久但结尾更轻的那次 | 书中第 35 章 |
| 老年词造句 | 造句后走路变慢，本人无察觉 | 启动效应示例 |
| 诚实盒 | 换图片（花或眼睛）改变投币金额 | 书中案例 |
| 琳达问题 | 高智商受试者多数犯合取谬误 | 1983 年实验 |
| 悉尼歌剧院 | 预算翻十几倍，规划谬误的经典样本 | 书评引用 |
