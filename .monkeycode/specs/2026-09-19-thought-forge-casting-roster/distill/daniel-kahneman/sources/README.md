## 二、可确认为原著与本人表述的

- "我们的大脑有快与慢两种作决定的方式"，系统 1 "固守眼见即为事实的原则"，系统 2 "很懒惰，经常走捷径"。
- 损失厌恶：损失的痛苦约为同等收益带来快乐的 2—2.5 倍。
- 峰终定律：记忆自我按峰值与结尾来评价经历；书中冷水实验里 80% 的人选了更久但结尾更轻的那一次。
- 规划谬误与事前验尸：拍板前先假设一年后已惨败，请每人写下惨败原因。
- "专家预测的准确度比不上扔飞镖的猴子"（他引用并推广的研究结论）。
- 诺奖访谈中他本人说：如果那篇论文发在别的期刊，就不会有今天的诺贝尔奖——"这完全是偶然"。
- 清华对话中他本人说："有判断，哪里就有噪声，而且它比你想象的还要多"；保险公司 50 位经理对同一案例定的保费差 50% 以上。

## 三、标为「转述」或他人表述的

- 系统 1／系统 2 是书中的**描述性虚构**（原著目录自陈"两个虚拟出来的角色"），不是解剖学结构。
- 噪声三分类（水平噪声、模式噪声、情境噪声）与去噪做法（独立判断取平均、结构化判断）——出自《噪声》，为要点归纳。
