# 阶段 1：五路提取候选池（塞利格曼）

## 一、框架提取

| 候选 | 要点 | 出处 |
|---|---|---|
| 习得性无助 | 努力与结果脱钩后学会放弃 | 1967 经典实验 |
| 解释风格 | 永久性、普遍性、个人化三个维度 | 《活出最乐观的自己》 |
| 习得性乐观 | 指认并反驳悲观想法 | 语录与原著 |
| PERMA | 情绪、投入、关系、意义、成就 | 《持续的幸福》 |
| VIA 优势 | 24 项品格优势分类 | Peterson & Seligman 2004 |
| 洛萨达比例 | 职场 3:1、家庭 5:1 | 《持续的幸福》目录 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 你无法控制经历，但可以控制解释 | 归因是变量 |
| 大部分时间乐观、偶尔悲观 | 轻度悲观的保护作用 |
| 优势优先于短板 | 真实的幸福来自发挥优势 |
| 小胜积累重建掌控感 | 降低门槛，重新体验"我能改变" |
| 无助会外溢为冷漠 | 后续研究：社会维度的代价 |
| 痛苦本身有功能 | 不否认负面情绪的作用 |

## 三、案例提取

| 候选 | 内容 | 出处 |
|---|---|---|
| 三组犬实验 | 不可控电击组约 2/3 不再尝试逃脱 | 1967 实验 |
| 大象与小木桩 | 幼年被绑、长大不再尝试 | 科普文引用 |
| 保险销售员乐观与业绩 | 解释风格预测坚持度 | 书中研究 |
| 三件好事练习 | 写下三件好事并分析原因 | 《持续的幸福》 |
| 积极主动式回应 | 对他人好消息的回应方式影响关系 | 书中第 3 章 |

## 四、反例提取

| 候选 | 内容 |
|---|---|
| 把失败归为"我天生不行" | 永久 + 普遍 + 个人化，最伤 |
| 强行正能量 | 忽略"偶尔悲观"的必要性 |
| 只修补短板 | 忽略优势带来的投入与意义 |
| 无助的外溢 | 变得冷漠，减少助人倾向 |
| 把比例当考核 | 表演式积极 |

## 五、术语提取

习得性无助、习得性乐观、解释风格、永久性、普遍性、个人化、PERMA、VIA、三件好事、感恩日记、突出优势、积极主动式回应、洛萨达比例、65% 极限。
