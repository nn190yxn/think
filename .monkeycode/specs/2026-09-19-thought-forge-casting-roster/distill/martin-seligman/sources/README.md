## 二、可确认为本人原话或原著表述的

- "你无法控制你的经历，但你可以控制你的解释。"
- "成功的生活需要大部分时间的乐观和偶尔的悲观。轻度的悲观使我们在做事之前三思；乐观使我们的生活有梦想、有计划，有未来。"
- "真实的幸福源于发现自己的优势和美德，并在生活中充分发挥它们。"
- "现在已经有很好的方法来培养乐观情绪，这个方法就是指认出自己的悲观想法，并且反驳它。"
- PERMA 五要素：积极的情绪、投入、良好的人际关系、意义与目的、成就感。
- 洛萨达比例：职场 3:1、家庭 5:1。

## 三、标为「转述」的

- 习得性无助实验：不可控电击组的犬中约 2/3 在后来可逃的情况下不再尝试。
- 解释风格三维度：永久性维度决定放弃多久，普遍性维度决定无助扩散到多少领域。
- 三件好事练习、感恩日记、突出优势练习的用法与效果表述。
- 65% 极限：药物与大部分心理治疗做到最好也不过 65%。
