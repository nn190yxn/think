# 阶段 0：蒙台梭利的整体理解

## 一、主旨

**儿童自己会成长；成人要做的不是灌输，而是准备好环境、观察、然后退到后面。**

蒙台梭利把教育从"老师讲、孩子听"反转成"环境设计 + 自主探索 + 成人观察"。她的两个支点是：孩子有**吸收性心智**（像海绵吸环境）与**敏感期**（特定阶段对特定能力强吸收）。成人干预过多，反而破坏这个过程。

## 二、骨架

1. **以儿童为中心**：教师是观察者、环境准备者、引导者。
2. **吸收性心智**：0—6 岁吸收环境中的一切。
3. **敏感期**：在特定阶段教特定的事，事半功倍。
4. **有准备的环境**：教具可自由取用、可归位，环境本身就是课程。
5. **混龄**：幼儿模仿、大孩子巩固与照顾他人。
6. **自我纠错的教具**：让孩子自己发现错，而不是被指出错。
7. **自由与规则并行**：自由不是放任。
8. **成人退后**：反对包办与过分干涉。

## 三、关键术语

| 术语 | 含义 |
|---|---|
| 儿童之家 | 1907 年罗马的第一所学校 |
| 吸收性心智 | 像海绵一样吸收环境 |
| 敏感期 | 特定能力强吸收的窗口 |
| 有准备的环境 | 按儿童需要布置的空间与教具 |
| 混龄 | 约三岁跨度的班级 |
| 感官教育 | 通过教具训练感官辨别力 |
| 刺激的孤立性 | 教具只训练一种感官属性 |
| 操作的顺序性 | 操作步骤有序 |
| 自我纠错 | 教具本身让孩子看见错误 |
| 三段式练习法 | 命名、确认、记忆 |
| 工作本能 | 儿童内在的做事驱动力 |
| 自由与规则 | 自由以不打扰他人为界 |

## 四、批判与盲点

1. **师资缺口巨大**：合格蒙氏教师比例不足 13%，行业里七成机构把教具当玩具。
2. **依赖环境与教具**：条件缩水效果就大打折扣，不是"有教具就行"。
3. **升学衔接**：不强调应试，进入标准答案为主的小学阶段可能需要适应期。
4. **要求家庭一致**：家长若仍习惯包办，效果会被消解。
5. **成人退后的难度**（我们的判断）：这套方法最难的不是买教具，而是成人忍住不插手；对急性子的家长和追求短期可见成果的机构，天然不友好。

## 五、可应用场景

安排孩子的活动与空间、判断"该教还是该等"、选择早教机构，以及家庭里"要不要帮孩子做完"这类日常判断。
