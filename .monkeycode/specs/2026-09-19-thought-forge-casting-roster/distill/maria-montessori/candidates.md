# 阶段 1：五路提取候选池（蒙台梭利）

## 一、框架提取

| 候选 | 要点 | 出处 |
|---|---|---|
| 以儿童为中心 | 教师是观察者与引导者 | 行业解读 |
| 吸收性心智 | 0—6 岁吸收环境一切 | 核心理念 |
| 敏感期 | 特定阶段对特定能力强吸收 | 核心理念 |
| 有准备的环境 | 环境即课程 | 核心理念 |
| 混龄 | 约三岁跨度 | 行业观察 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 成人退后 | 反对包办与过分干涉 |
| 自由不是放任 | 自由以规则为界 |
| 让孩子自己发现错 | 自我纠错教具 |
| 顺应自然规律 | 不搞成人主导的灌输 |
| 观察先于干预 | 先看清孩子在做什么 |
| 家校一致 | 家庭观念不契合会消解 |
