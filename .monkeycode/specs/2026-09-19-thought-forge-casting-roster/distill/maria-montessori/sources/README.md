## 二、可确认为其体系核心的

- 1907 年在罗马创办第一所「儿童之家」；她是意大利首位女医学博士。
- **以儿童为中心**：反对填鸭式教学，教师是观察者、环境准备者和引导者，不是知识灌输者。
- **吸收性心智**：0—6 岁的孩子像海绵一样吸收环境中的一切。
- **敏感期**：特定阶段对某些能力（语言、秩序、精细动作）有超强学习欲望；例如 2—4 岁是秩序敏感期。
- **有准备的环境**：教具按类别摆放、儿童可自由取用与归位。
- 教师不是「教」师而是「导」师：经专业培训并持证上岗，国际认证体系有 AMI、AMS 等。
- **混龄**：年龄跨度通常约三岁，便于幼儿观察模仿、大孩子巩固与照顾他人。
- 感官教育教具的两个特点：**刺激的孤立性**、**操作的顺序性**；教具有自我纠错设计（让孩子自己发现错误）。
- **三段式练习法**：命名、确认、记忆（这也是语言教学的基本方法）。
- **自由与规则并行**：自由不是放任，需遵守归位、安静、不打扰他人等规则。
- 她主张尊重儿童、反对成人过分干涉，认为儿童具有「工作本能」。

## 三、标为「转述」的

- 教具四大类：感官、语言、数学、文化（部分体系含日常生活）。
- 混龄的代价：对教师观察与引导技巧要求很高。
- 她认为教育应顺应儿童自然成长规律，而非成人主导的灌输。
- 受其理念影响的知名人物中常被提及的有比尔·盖茨、彼得·德鲁克、乔治·克鲁尼（转述，作为影响力佐证）。

## 四、核验记录

2026-09-21：条目经全网检索核对，来源包括三篇行业解读、两篇观念与方法提炼、一本专著简介。

**批评与争议同时留存**（写入盲点与边界）：
1. **师资缺口巨大**：国内蒙氏教师缺口约 30 万，而合格蒙氏教师比例不足 13%；行业观察显示七成机构把蒙氏教具当玩具。
2. **环境与教具依赖强**：依赖特定教学环境、专业教具与混龄配置，条件不具备时效果会大打折扣。
3. **与传统升学机制衔接**：不强调应试训练，进入以标准答案和考试为主的小学阶段可能需要适应期。
4. **对家庭观念契合度要求高**：与蒙氏理念契合的家庭效果显著；若家长仍习惯包办，效果会被消解。
5. **政策背景**：蒙氏教育相关职业标准于 2026 年 3 月被纳入国家职业认证框架（可作为行业规范的进展）。
