# 阶段 4：选角测试用例（达利欧）

## 一、该出手的

| 提问 | 期望选出的单元 |
|---|---|
| 同一个错误我犯了三次，为什么。 | 把原则写下来、痛苦＋反思＝进步 |
| 团队开会没人反对我，我该高兴吗。 | 把反驳当避雷针、头脑极度开放 |
| 我要不要在公司推行完全透明。 | 极度求真与极度透明、别照搬别人的原则 |
| 决策该听谁的，资历最老的吗。 | 创意择优与可信度加权 |
| 项目卡住了，不知道从哪下手。 | 五步流程 |

## 二、不该出手的（诱饵）

| 提问 | 为什么不该由他出手 |
|---|---|
| 帮我算一下这笔投资的收益率。 | 算术题，不是原则问题 |
| 我该不该和这个人结婚。 | 属人生意义与价值判断，他的框架给不了答案 |
| 明天穿什么。 | 常识级问题 |

## 三、边界模糊的

| 提问 | 判定要点 |
|---|---|
| 我想在团队里推行「极度透明」，把每个人的问题都公开。 | **必须先说边界**：桥水文化本身被批「磨损员工自信」，且透明需要信任与能力基础；该触发「极度求真与极度透明」+「别照搬别人的原则」 |
| 我该不该照抄大公司的管理制度。 | 该触发「别照搬别人的原则」——他本人就要求质疑他的每一句话 |
| 员工被我批评后情绪低落，是不是太玻璃心。 | 该触发「头脑极度开放」与「理解人与人大不相同」：他本人早年也因说话太直接被反馈过，并据此改了沟通方式 |

## 四、跨同门混淆

| 提问 | 容易混淆 | 正确判断 |
|---|---|---|
| 我把教训记下来了，但还是不改。 | 把原则写下来（术）vs 痛苦＋反思＝进步（道） | 记下来是术；不反思等于公式没走完，是道 |
| 大家都同意，要不要拍板。 | 把反驳当避雷针（气）vs 创意择优（法） | 先补反对意见（气），再按权重定（法） |
| 该不该信一个新手的话。 | 创意择优与可信度加权（法）vs 别照搬（势） | 判断权重来源选前者；判断规则移植选后者 |
