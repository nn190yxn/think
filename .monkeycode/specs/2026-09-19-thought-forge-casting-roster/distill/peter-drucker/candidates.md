# 阶段 1：五路提取候选池（德鲁克）

## 一、框架提取

| 候选 | 要点 | 出处 |
|---|---|---|
| 有效性的五项实践 | 时间、贡献、长处、要事、决策 | 《卓有成效的管理者》全书结构 |
| 目标管理与自我控制 | MBO 原名，取代支配式管理 | 《管理的实践》1954 |
| 德鲁克三问 | 事业是什么、顾客是谁、顾客重视什么 | 全书 |
| 决策的五个要素 | 有效决策的结构 | 第 6 章 |
| 知识工作者 | 知识属于个人，组织只能租用 | 1959 年提出 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 有效可以学会 | 不是天赋，是习惯组合 |
| 成果在外部 | 组织内部只有成本 |
| 先有见解，再找事实 | 事实用于检验判断 |
| 用人所长 | 长处是机会，短处是问题 |
| 摆脱昨天 | 对现在不会启动的事，停掉它 |
| 一次只做好一件事 | 贪多必失 |
| 我要贡献什么 | 从努力转向成果 |

## 三、案例提取

| 候选 | 内容 | 出处 |
|---|---|---|
| 通用汽车十八个月调研 | 他趴在现场看工人怎么干活，写出《公司的概念》 | 评述文章 |
| 两个决策案例 | 第 6 章开头用于拆解决策要素 | 目录与内容简介 |
| 中层经理的影响 | 其行动与决策直接影响企业绩效与方向 | 内容简介 |
| 张瑞敏常读此书 | 「不知读了多少遍，常读常新」 | 书目推荐语 |
| 平凡人做不平凡的事 | 组织的目的是让平凡人做出不平凡的事业 | 内容简介 |

## 四、反例提取

| 候选 | 内容 |
|---|---|
| 目标层层摊派 | 违背「共同制定」的原意 |
| 只看数字逼出短期行为 | 戴明批评的核心 |
| 盯着下属缺点 | 磨掉短处的同时磨掉长处 |
| 待办清单越排越长 | 只排序不删除，等于什么都没定 |
| 把 MBO 当管控工具 | 与他提出的「自我控制」相反 |

## 五、术语提取

有效性、目标管理与自我控制、德鲁克三问、时间诊断、贡献、用人所长、要事优先、摆脱昨天、决策五要素、反面意见、知识工作者、社会生态学家。
