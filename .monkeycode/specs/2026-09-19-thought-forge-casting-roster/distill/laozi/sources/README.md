## 二、可确认为《道德经》原文的

- 「道常无为而无不为。」（第三十七章）
- 「上善若水。水善利万物而不争，处众人之所恶，故几于道。」（第八章）
- 七善：居善地、心善渊、与善仁、言善信、政善治、事善能、动善时。（第八章）
- 「天下莫柔弱于水，而攻坚强者莫之能胜，以其无以易之。」（第七十八章）
- 「持而盈之，不如其已；揣而锐之，不可长保。金玉满堂，莫之能守；富贵而骄，自遗其咎。功成名遂身退，天之道。」（第九章）
- 「天长地久……是以圣人后其身而身先，外其身而身存。非以其无私邪？故能成其私。」（第七章）
- 「三十辐共一毂，当其无，有车之用……故有之以为利，无之以为用。」（第十一章）
- 「致虚极，守静笃……归根曰静，静曰复命。复命曰常，知常曰明。不知常，妄作凶。」（第十六章）
- 「知人者智，自知者明。胜人者有力，自胜者强。」（第三十三章）
- 「为学日益，为道日损。损之又损，以至于无为。」（第四十八章）
- 「故物或损之而益，或益之而损。」（第四十二章）
- 「多言数穷，不如守中。」（第五章）
- 「天下多忌讳，而民弥贫……法令滋彰，盗贼多有。」（第五十七章）
- 「为者败之，执者失之。」（第六十四章）
- 「治大国若烹小鲜。」（第六十章）

## 三、标为「转述」的

- 以水为根喻的三组概念：致虚、用柔、处下（不争）。
- 无为的正解：不是什么都不做，而是不妄为、不强为——顺自然之道而行。
- 版本差异：传世本第四十一章作「大器晚成」，马王堆帛书甲乙本均作「大器免成」（免＝无需人为干预）。
- 「反者道之动」被后世视为其辩证法则的概括。

## 四、核验记录

2026-09-21：条目经全网检索核对，来源包括两个古籍原文库、一篇学术研究、一篇当代解读与两篇书评文章。

**最常见的误解与纠误同时留存**（写入边界）：
1. **把无为当消极避世的证据**：解读明确指出这是「根本性的误解」——无为是不妄为、不强为。
2. **把上善若水当道德训诫**：原文的关键是「几于道」，水的价值在于接近道，而不是某种德性标签。
3. **把道的思想当治理万能药**：其主张针对的是当时统治者过度干预的处境，强调少折腾；对需要主动作为的场景并不适用。
