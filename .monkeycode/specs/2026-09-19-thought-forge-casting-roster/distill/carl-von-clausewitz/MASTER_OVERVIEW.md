# 阶段 0：克劳塞维茨的整体理解

## 一、主旨

**战争是政治的继续；而现实中，摩擦与迷雾让任何计划都只能部分实现。**

克劳塞维茨的价值有两层：一层是**目的层**——暴力必须服从政治目标，手段不能与目的脱钩；一层是**现实层**——摩擦、情报不准、执行偏差会让最完美的计划打折。他因此被称为"计划赶不上变化"的祖宗。

## 二、骨架

1. **战争从属于政治**：政治目标是目的，战争是手段。
2. **战争是扩大了的搏斗**：暴力是其本性，不能只当技术问题。
3. **摩擦**：无数小事累积，使实际效果达不到纸面计划。
4. **迷雾与情报**：信息永远不完整，决策在不确定中做出。
5. **精神要素**：武德、胆量、坚忍是决定性的力量。
6. **兵力集中**：在决定性的点集中尽可能多的力量。
7. **防御更强**：防御是更有力的形式，先立于不败再转入进攻。
8. **计划要留余地**：计划必然被打断，必须给临机处置留空间。

## 三、关键术语

| 术语 | 含义 |
|---|---|
| 战争是政治的继续 | 目的与手段不可分离 |
| 扩大了的搏斗 | 对战争本性的定义 |
| 摩擦 | 现实中一切阻滞的总和 |
| 迷雾 | 情报不准与不确定 |
| 军事天才 | 在不确定中判断的能力 |
| 精神要素 / 武德 | 决定胜负的软力量 |
| 兵力集中 | 在决定点集中力量 |
| 防御的优势 | 防御是更强有力的形式 |
| 紧张与平静 | 战争的力学状态 |

## 四、批判与盲点

1. **唯心史观**：权威传记评述指出，他把政治理解为国家人格化的智慧，看不到战争的经济根源，也无法区分正义与非正义战争的阶级实质。
2. **著作未完成**：进攻与战争计划两篇都是草稿，部分结论需要谨慎引用。
3. **被各取所需**：同一套理论曾被毛奇、施利芬推崇为德军教材，也被其他政权引用；理论本身不保证用对。
4. **战例的时代性**（我们的判断）：其经验来自拿破仑战争前后的战例，技术、后勤与舆论环境已大不相同，需转译。
5. **不适合直接指导日常决策**（我们的判断）：他的框架是极端对抗情境下的思考方式，用在合作型场景会过度防御。

## 五、可应用场景

面对高度不确定、对手会反制、信息不完整的对抗局面（竞争、谈判、危机处置），以及"计划被打乱时怎么办"这类问题。
