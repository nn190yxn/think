# 阶段 4：选角测试用例（克劳塞维茨）

## 一、该出手的

| 提问 | 期望选出的单元 |
|---|---|
| 计划做得好好的，一执行就乱。 | 摩擦、计划要给临机处置留空间 |
| 对手会反制，我怎么排打法。 | 在决定点集中力量、出敌不意（见战略概论） |
| 我们该先守还是先攻。 | 防御是更强有力的形式 |
| 团队士气低，还能不能打。 | 精神要素：武德、胆量、坚忍 |
| 打赢了这笔生意，但可能毁掉长期关系。 | 战争从属于政治 |

## 二、不该出手的（诱饵）

| 提问 | 为什么不该由他出手 |
|---|---|
| 我和同事该怎么合作。 | 他的框架面向对抗情境，用在合作场景会过度防御 |
| 这批货的成本怎么算。 | 算术题 |
| 明天穿什么。 | 常识级问题 |

## 三、边界模糊的

| 提问 | 判定要点 |
|---|---|
| 我能不能把商业竞争当战争来打。 | **必须先说边界**：他是极端对抗情境下的思考方式；商业里多数关系是重复博弈与合作，全面战争隐喻会导致过度消耗与失信 |
| 对手很强，我是不是该一直防守。 | 该触发「防御是更强有力的形式」，但边界：防御是为了赢得时间转入进攻，不是永久退让 |
| 计划总被打乱，是不是就别做计划了。 | 该触发「摩擦」与「计划留余地」：不是不计划，是计划里必须含应变分支 |

## 四、跨同门混淆

| 提问 | 容易混淆 | 正确判断 |
|---|---|---|
| 我该不该继续追这个目标。 | 战争从属于政治（道）vs 计划留余地（势） | 判断"目的还成立吗"用道；判断"执行怎么调"用势 |
| 信息不全要不要动手。 | 迷雾与情报（法）vs 精神要素（气） | 判断信息风险用法；判断勇气与士气用气 |
| 资源怎么铺。 | 在决定点集中力量（术）vs 防御优势（术） | 判断进攻配置用前者；判断守势用后者 |
