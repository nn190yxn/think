# 阶段 1：五路提取候选池（克劳塞维茨）

## 一、框架提取

| 候选 | 要点 | 出处 |
|---|---|---|
| 战争从属于政治 | 目的与手段不可分离 | 第一篇第一章 |
| 摩擦 | 现实阻滞的总和 | 第一篇第七章「战争中的阻力」 |
| 迷雾与情报 | 信息不完整是常态 | 第一篇第六章「战争中的情报」 |
| 精神要素 | 武德、胆量、坚忍 | 第三篇第三至七章 |
| 兵力集中 | 空间与时间上的集中 | 第三篇第十一、十二章 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 手段不能脱离目的 | 打赢不是目的本身 |
| 防御是更强的形式 | 先不败再求胜 |
| 在决定点集中力量 | 不平均用力 |
| 出敌不意 | 突然性带来优势 |
| 计划必须留余地 | 一定会被打断 |
| 精神力量不可忽视 | 摧毁的不只是物质 |
