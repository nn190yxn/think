## 二、可确认为原著核心表述的

- 「战争无非是政治通过另一种手段（即暴力）的继续。」
- 「政治目标是目的，战争是达到政治目标的手段，不能将手段和它所服务的政治目标分开来考虑。」
- 在回答「什么是战争」时，他把战争说成「无非是扩大了的搏斗」。
- 八篇结构：论战争的性质、论战争理论、战略概论、战斗、军队、防御、进攻（草稿）、战争计划（草稿）。
- 论战争的性质篇下的章节：什么是战争、战争中的目的和手段、军事天才、战争中的危险、战争中的劳累、**战争中的情报**、**战争中的阻力**（即摩擦）。
- 战略概论篇下的章节：精神要素、主要的精神力量、军队的武德、胆量、坚忍、数量上的优势、出敌不意、诡诈、空间上的兵力集中、时间上的兵力集中、军事行动中的间歇、紧张与平静——战争的力学定律。
- 防御篇的核心判断：防御本身是比进攻更强有力的一种作战形式；主张借助防御赢得时间，取得优势后转入进攻。
- 他研究过 1566—1815 年间的 130 多个战例。

## 三、标为「转述」的

- 摩擦：现实中无数小事累积，使实际战果永远达不到纸面计划的效果；信息不完整、命令延误、执行偏差都属于摩擦。
- 迷雾：情报不准与不确定，是战争决策的常态。
- 「战争是政治的延续」被概括成一句话，但其原文语境包含「不能把手段与目的分开考虑」的限定。
- 他看重精神力量：消灭敌人军队不只是消灭物质力量，还包括摧毁其精神力量。

## 四、核验记录

2026-09-21：条目经全网检索核对，来源包括《战争论》完整目录、牛津通识课导读简介、权威传记内容简介（含批评）、百科词条与一篇战略讨论。

**批评同时留存**（写入盲点）：
1. **唯心史观**：传记评述指出，他对战争的认识总体仍未摆脱唯心主义思想体系的窠臼；他把政治理解为国家人格化的智慧，**看不到产生战争的基础是经济利益的冲突**，因而无法揭示战争的本质，也不能明确区分正义战争与非正义战争的阶级实质。
2. **著作未完成**：第六篇防御之后，进攻与战争计划两篇都是草稿。
3. **被各取所需**：19 世纪末经毛奇与施利芬推崇成为德军教材，也被其他政权引用；同一套理论在不同立场手里指向不同结论。
4. **战例基础的时代性**（我们的判断）：其经验来自拿破仑战争前后的战例，技术与舆论环境已与当代不同，需要转译而非照搬。
