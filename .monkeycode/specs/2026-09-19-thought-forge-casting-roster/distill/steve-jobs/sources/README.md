## 二、可确认为原话的

- "Stay hungry, stay foolish."（求知若饥，虚心若愚——苹果官方中文译法）
- "你们的时间很有限，所以不要浪费时间去过别人的生活。"（2005 斯坦福演讲）
- "记住你即将死去，是我知道的避免患得患失最好的办法。"（2005 斯坦福演讲，意译）
- "好的艺术家只是照抄，而伟大的艺术家窃取灵魂。"（他引用毕加索）
- "当你拥有真正优秀的人才时，你不必对他们太纵容；你期望他们做出好成绩，你就能让他们做出好成绩。"（《史蒂夫·乔布斯传》）
- 现实扭曲力场的构成："极富魅力的措辞风格、不屈的意志和让现实屈从于自己意图的热切渴望。"（《史蒂夫·乔布斯传》第十一章）

## 三、标为「转述」的

- 从用户体验倒推技术：他要求"在 600 美元以内做出来，而且要比市面上所有手机都好用"
- 对 1000 件事说不（"I'm as proud of the things we haven't done as the things we have done"的归纳）
- A 级人才只与 A 级人才合作（They only hire A players 的归纳）

## 四、核验记录

2026-09-21：条目经全网检索核对，来源包括 2005 斯坦福演讲的中英对照、传记原文摘录、图书馆书目与多家媒体分析。原话部分经多来源一致；其余标「转述」。

**负面评价同时留存**（写入盲点，不美化）：传记明确记载"史蒂夫就是忠诚的反义词"（早期工程师安迪·赫茨菲尔德语）；艾萨克森也指出"现实扭曲力场只是换了种好听的说法来描述乔布斯喜欢说谎的特性"。这类记载构成对方法的必要限定。
