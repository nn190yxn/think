# 阶段 1：五路提取候选池（王阳明）

## 一、框架提取

| 候选 | 要点 | 出处 |
|---|---|---|
| 心即理 | 理在心中，莫向外求 | 《传习录·上》 |
| 知行合一 | 知是行之始，行是知之成 | 《传习录》 |
| 致良知 | 把良知推到事事物物 | 晚年宗旨 |
| 事上磨炼 | 在事上磨，方立得住 | 《传习录·上》 |
| 四句教 | 心体、意动、良知、格物 | 天泉证道 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 做不到就是不知道 | 知而不行只是未知 |
| 格物是格心 | 不是观察外物是去私欲 |
| 静亦定，动亦定 | 定不在静处 |
| 此心不动，随机而动 | 心定行动活 |
| 良知人人本有 | 不必外求权威答案 |
| 客观知识仍须外学 | 心学不替代科学 |
