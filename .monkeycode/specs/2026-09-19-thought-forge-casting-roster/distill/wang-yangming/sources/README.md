## 二、可确认为原著表述的

- 龙场悟道原话：「圣人之道，吾性自足，向之求理于事物者，误也。」
- 「心即理也。天下又有心外之事、心外之理乎？」（《传习录·上》）
- 「你未看此花时，此花与汝心同归于寂。你来看此花时，则此花颜色一时明白起来。便知此花不在你的心外。」（《传习录·下》）
- 知行合一：「知是行之始，行是知之成」；「知而不行，只是未知。」
- 事上磨炼：「人须在事上磨，方立得住；方能静亦定，动亦定。」（《传习录·上》）
- 四句教：「无善无恶心之体，有善有恶意之动，知善知恶是良知，为善去恶是格物。」（《传习录·下》，天泉证道）
- 「破山中贼易，破心中贼难。」
- 用兵秘诀：「此心不动，随机而动。」
- 临终遗言：「此心光明，亦复何言。」
- 事功：1517 年巡抚南赣，一年余平定数十年匪患，推行十家牌法；1519 年平定宁王之乱，仅用 43 天生擒宁王。

## 三、标为「转述」的

- 三大命题：心即理、知行合一、致良知。
- 格物即格心：不是去观察外物，而是格除内心杂念私欲，让本心良知显现。
- 致良知的四层次第：明良知本体、省察克治、事上磨炼、知行合一。
- 两条常见误区：一味向内求易成空想；一味追外物则被欲望吞噬。

## 四、核验记录

2026-09-21：条目经全网检索核对，来源包括一篇逐条标注原文出处的心学归纳、一部专著的义理目录、一篇带尖锐批评的书评、两篇考述与一篇落地路径分析。

**批评同时留存**（写入盲点与边界）：
1. **唯心体系与落地之间的距离**：书评指出心学是彻底的唯心学说，提供的是「价值理性」（应当如何），却几乎给不出「如何落地」；面对房贷、绩效、deadline，「致良知」能解决什么具体问题，是需要回答的。
2. **被成功学收编**：「知行合一」在知识付费行业被简写成执行力鸡汤——「想，都是问题；做，才是答案」，这恰说明其原始语境失落。
3. **后学空谈**：顾炎武在《日知录》中批评明末「以明心见性之空言，代修己治人之实学」；评价指出阳明后学大量流入讲学与清议，空谈心性者多于真能经世济用者。
4. **边界**（其本人在世时已强调）：心即理不是「我即真理」的主观任性；客观知识（科学、技术、法规）仍需向外学习。
