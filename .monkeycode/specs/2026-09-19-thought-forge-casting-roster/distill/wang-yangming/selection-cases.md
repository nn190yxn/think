# 阶段 4：选角测试用例（王阳明）

## 一、该出手的

| 提问 | 期望选出的单元 |
|---|---|
| 道理我都懂，就是做不到。 | 知行合一、省察克治 |
| 我总在纠结，听了很多人建议还是没主意。 | 心即理、致良知 |
| 一遇事就慌，静下来还好，一动就乱。 | 此心不动，随机而动、事上磨炼 |
| 知道该做但一直拖。 | 知行合一、省察克治 |
| 我做的事违背自己的价值观，很难受。 | 心即理、致良知 |

## 二、不该出手的（诱饵）

| 提问 | 为什么不该由他出手 |
|---|---|
| 我最近一直睡不着、情绪很低。 | 临床边界：需要循证评估与专业干预，不能用"事上磨"替代 |
| 这个项目投资回报多少。 | 算术与财务问题 |
| 明天穿什么。 | 常识级问题 |

## 三、边界模糊的

| 提问 | 判定要点 |
|---|---|
| 我照着心里想的做，是不是就是知行合一。 | **必须先说边界**：心即理不是"我即真理"的主观任性，私欲遮蔽时心里的理会失真；该触发「心即理」并同时给出「省察克治」 |
| 我要不要辞职去做想做的事。 | 可以讨论，但边界：客观知识与现实条件仍需向外评估；该触发「心即理」+「心学的边界」，不鼓励只凭感觉决策 |
| 这套学问能不能当管理工具用来要求员工。 | 边界：它是修己之学，不是考核工具；把它变成对他人的要求，正是顾炎武批评的那类空谈 |

## 四、跨同门混淆

| 提问 | 容易混淆 | 正确判断 |
|---|---|---|
| 我该怎么选。 | 心即理（道）vs 四句教（器） | 判断标准在哪用道；日常自查用器 |
| 我做不到，是不是意志力问题。 | 知行合一（法）vs 此心不动（气） | 判断"懂没懂"用法；判断情绪扰动用气 |
| 我该静下来修炼还是去做事。 | 事上磨炼（术）vs 致良知（道） | 功夫在下手处用术；方向用道 |
