# 阶段 0：王阳明的整体理解

## 一、主旨

**是非的标准在你心里，但只有落到行动上才算真的知道；功夫不在静坐，在事上磨。**

王阳明的三句话是一套连续动作：**心即理**（标准在内不在外）→ **致良知**（把那点本有的判断力扩充出来）→ **知行合一**（没做到就是还不知道）。他最反对的是"道理都懂却做不到"这种自我安慰——在他看来，那根本不是懂。

## 二、骨架

1. **心即理**：天理不在外物，在人心；但私欲遮蔽时，心中的理会失真。
2. **致良知**：人人本有良知，功夫是把它推到事事物物上。
3. **知行合一**：知是行之始，行是知之成；知而不行，只是未知。
4. **格物即格心**：格除内心杂念私欲，而非向外观察。
5. **事上磨炼**：在得失、荣辱、顺逆中练，不在静坐中练。
6. **省察克治**：起心动念时分辨这是良知还是私欲。
7. **此心不动，随机而动**：心不被扰动，行动随情境而变。
8. **四句教**：心之体、意之动、知善知恶、为善去恶。

## 三、关键术语

| 术语 | 含义 |
|---|---|
| 心即理 | 天理在人心 |
| 致良知 | 把本有的良知扩充推行 |
| 知行合一 | 知与行本是一体 |
| 格物 | 格除内心杂念私欲 |
| 事上磨炼 | 在实事中练心 |
| 省察克治 | 起念时反观辨别 |
| 此心不动，随机而动 | 心定而行动灵活 |
| 四句教 | 心学的总纲口诀 |
| 良知 | 内在的是非判断力 |

## 四、批判与盲点

1. **价值理性给不出落地路径**：书评指出它告诉人「应当如何」，却几乎给不出「如何落地」；面对具体压力，需要另配可执行的工具。
2. **被成功学化**：「知行合一」被简写成执行力鸡汤，原始语境失落。
3. **后学空谈**：顾炎武批评明末「以明心见性之空言，代修己治人之实学」；阳明后学中空谈心性者多于经世济用者。
4. **不能用来否定外部知识**（其本人已强调）：客观知识、技术、法规仍需向外学习；心学针对的是道德判断与价值选择的根源。
5. **不适合替代心理治疗**（我们的判断）：情绪与心理困扰需要循证评估，「事上磨」不能替代专业干预。

## 五、可应用场景

"道理都懂就是做不到"、内耗与纠结、在压力中如何保持判断，以及要不要把价值观落到具体行动这类问题。
