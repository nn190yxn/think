# 阶段 1：五路提取候选池（纳瓦尔）

## 一、框架提取

| 候选 | 要点 | 出处 |
|---|---|---|
| 财富公式 | 特定知识 × 杠杆 × 所有权 × 长期主义 | 《纳瓦尔宝典》财富篇 |
| 四类杠杆 | 劳动力、资本、媒体、代码 | 宝典财富篇、公开访谈 |
| 无需许可的杠杆 | 代码与媒体不需要别人点头 | 公开访谈 |
| 欲望管理 | 欲望是与自己签的受苦合约 | 宝典幸福篇 |
| 判断力优先 | 杠杆越长，判断越致命 | 宝典财富篇 |
| 产品化自己 | 把能力变成可复制、可规模化的产出 | 宝典财富篇 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 与长期的人玩长期的游戏 | 复利需要时间与稳定的对手盘 |
| 没有快速致富的教程 | 声称有的，是想赚你的钱 |
| 至少精通一件：造或卖 | 出售与构建是双翼 |
| 靠真实逃离竞争 | 竞争是模仿，独特性是护城河 |
| 幸福是减少，不是得到 | 减少执念、比较、必须 |
| 时间是唯一不可再生资源 | 用钱买时间，别用时间换钱 |

## 三、案例提取

| 候选 | 内容 | 出处 |
|---|---|---|
| 一个人写的程序服务上百万用户 | 代码是零边际成本的自动劳动力 | 公开访谈与解读 |
| 一条内容被无限复制 | 媒体杠杆不受时间空间限制 | 公开访谈与解读 |
| 睡后收入与自由 | 真正的富有是对自己时间的控制权 | 读书笔记 |
| 长期关注的问题变成判断力 | 十年关注某一领域的人，能看出别人忽略之处 | 播客笔记 |

## 四、反例提取

| 候选 | 内容 |
|---|---|
| 用时间换钱 | 工资再高也是"时间 × 单价"，停下就归零 |
| 被热搜与群聊吃掉注意力 | 判断力最大的杀手是注意力浪费 |
| 杠杆放大的错误 | 判断不清时，杠杆加速毁灭 |
| 与人攀比 | 比较是痛苦的加速器 |
| 追热门行业 | 追热点不如找自己更自然擅长的事 |

## 五、术语提取

特定知识、杠杆、无需许可的杠杆、睡后资产、长期游戏、判断力、欲望管理、产品化自己、零边际成本、复利。
