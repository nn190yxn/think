# 阶段 4：选角测试用例（纳瓦尔）

## 一、该出手的

| 提问 | 期望选出的单元 |
|---|---|
| 我工资不低，但一停下来就没收入，怎么才能有安全感。 | 财富是睡后资产、杠杆 |
| 我在纠结要不要做副业，做内容还是接私活。 | 把自己产品化、杠杆（代码与媒体） |
| 有个朋友想拉我合伙做生意，说三年就能翻几倍。 | 与长期的人玩长期的游戏、没有快速致富的教程（法） |
| 我技术不错，但一直不擅长推销自己。 | 学会出售，也学会构建 |
| 同学都混得比我好，我一刷朋友圈就难受。 | 幸福是减少欲望、靠真实逃离竞争 |

## 二、不该出手的（诱饵）

| 提问 | 为什么不该由他出手 |
|---|---|
| 帮我改一份 PPT 的排版。 | 执行类请求，无判断问题 |
| 我该不该跟父母要钱买房。 | 家庭与结构性问题，他的框架有明显盲点（忽略结构性困境），应由其他视角处理 |
| 明天要不要请假。 | 常识级问题 |

## 三、边界模糊的

| 提问 | 判定要点 |
|---|---|
| 我该不该辞职去做自媒体。 | 该出手（财富是睡后资产 + 杠杆），但须提示他的盲点：初始资源不足时先保现金流 |
| 我要不要花两万块报一个"财富课"。 | 该触发"没有快速致富的教程"，边界在于：可验证的技能训练不在此列 |
| 现在很焦虑，怎么平静下来。 | 该触发"幸福是减少欲望"，但要提示边界：焦虑若源于现实风险，先处理风险而非修心 |

## 四、跨同门混淆

| 提问 | 容易混淆 | 正确判断 |
|---|---|---|
| 我该不该把全部时间投在写代码上。 | 杠杆（器）vs 学会出售与构建（术） | 判断资产形态选杠杆；判断能力短板选出售与构建 |
| 我总在换项目，一个都做不长。 | 长期游戏（法）vs 幸福是减少（气） | 若症状是关系与合作不稳，选长期游戏；若症状是欲望太多，选减少欲望 |
| 我的专长到底该做什么方向。 | 特定知识（法）vs 产品化自己（术） | 选方向选特定知识；定产出形式选产品化自己 |
