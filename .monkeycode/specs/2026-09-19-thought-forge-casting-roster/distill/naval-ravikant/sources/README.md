## 二、可确认为原话的

- "财富是那些即使你不工作，也能持续为你创造价值的资产。"
- "和长期主义的人，玩长期主义的游戏。"
- "世界上没有快速致富的教程。即使有，那也只是提供教程的人想从你身上赚钱。"
- 三种杠杆：资本、劳动力、以及"代码和媒体"这类零边际成本的杠杆。

## 三、标为「转述」的

- "欲望是你与自己签订的受苦合约。"
- "学会出售，学会构建。"（learn to sell, learn to build）
- "无需许可的杠杆"（permissionless leverage）
- 幸福是一种可习得的内在技能，通过减少欲望与活在当下来实现
- 靠真实逃离竞争（competition is for losers 的表述形态）
