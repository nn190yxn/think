# 阶段 0：查理·芒格的整体理解

## 一、这个人到底在教什么（主旨）

**把判断变成可复用的检查流程，靠"避免愚蠢"而不是"追求聪明"取胜。**

芒格不提供预测，他提供筛子：先用跨学科模型把问题放进框架，再用心理学清单检查自己在被什么驱动，最后用逆向法排除注定失败的路径。他反复强调：长期赢家不是最聪明的人，而是犯错最少的人。

## 二、骨架（他的方法论层次）

1. **多元思维模型（格栅）**——单一学科必然扭曲现实；模型须来自多学科，重要模型只有几十个。
2. **逆向排除**——不问"怎么成功"，先问"什么必然失败"。
3. **人类误判心理学**——把系统性心理倾向列成清单，决策前逐条对照（激励、嫉妒、避免不一致、避免怀疑等）。
4. **激励结构优先**——判断一个组织的行为，先看它被什么奖励。
5. **能力圈**——知道自己不知道什么，比知道什么更重要。
6. **耐心与集中下注**——大部分时间什么都不做，机会来时下重注。
7. **配得上**——把"如何得到"换成"如何值得"。

## 三、关键术语

| 术语 | 含义 |
|---|---|
| 格栅 / 思维模型 | 多学科模型组成的认知框架，经验挂在上面才有用 |
| 铁锤人倾向 | 只有一个模型的人，会把所有问题看成同一个问题 |
| 激励引起的偏见 | 由于奖励结构而产生的、当事人不自知的偏向 |
| lollapalooza 效应 | 多个心理倾向同向叠加，产生极端结果 |
| 能力圈 | 自己真正有判断力的领域边界 |
| 逆向 | 从"什么会失败"入手反推 |
| 祖母的规矩 | 先做该做的（胡萝卜），再做想做的（甜点）——自我约束的次序 |

## 四、批判与盲点（阶段 0 的批判部分）

1. **等待成本**：等"好球"在快速迭代的行业里会错过窗口期。芒格的方法偏向"可逆性低、赔率高"的场景。
2. **积累门槛**：方法建立在超大量阅读与长期经验上，对起点低的人不友好；他自己也承认靠五十年持续学习。
3. **清单可能机械化**：把心理倾向当清单打勾，容易变成形式主义。
4. **对技术与新事物的保守**：他在加密资产等问题上的公开态度，说明这套框架在"新范式"上可能过早否定。
5. **幸存者偏差**：他的案例多为成功者复盘，失败者用同一套方法的故事很少被记录。

## 五、可应用场景（决定后续单元的触发条件）

重大且不可逆的决策、投资、组织激励设计、人生方向的选择、以及"要不要争取一个机会"这类判断题。
