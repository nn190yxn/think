# 阶段 4：选角测试用例（芒格）

用于验证系统在真实提问下，是否会把他该出手的那条单元选出来。每类各一条，覆盖"该出手 / 不该出手 / 边界模糊"。

## 一、该出手的

| 提问 | 期望选出的单元 |
|---|---|
| 有个项目我已经投了一年多，明明看不到起色，但一想到放弃就等于承认自己错了，我就继续投。 | 逆向排除（先问什么会失败）、奖励与惩罚倾向（一致性问题） |
| 我想拿到那个位置，但感觉自己还差点东西，怎么办。 | 配得上 |
| 手上有闲钱，看到别人都在赚，心里急。 | 等好球再挥棒、少数机会下重注 |
| 团队执行总是走形，制度定了几版都一样。 | 激励结构优先 |

## 二、不该出手的（诱饵）

| 提问 | 为什么不该由他出手 |
|---|---|
| 明天面试穿什么颜色更稳。 | 常识级问题，任何单元都给不出增量 |
| 我想快速验证一个新点子，三天内做一个最小实验。 | 这属于快速试错场景，他的方法会拖慢节奏（他本人的盲点） |
| 帮我写一段自我介绍的开场白。 | 与他的方法体系无关 |

## 三、边界模糊的

| 提问 | 判定要点 |
|---|---|
| 现在这份工作还值不值得继续做满三年。 | 该出手（配得上 / 逆向排除），但须提示"可逆性"前提 |
| 要不要因为价格便宜买下这家公司。 | 该出手（能力圈 + 安全边际），但要防止把"便宜"误当能力圈内 |
| 我该不该原谅一个伤害过我的人。 | 应触发「戒嫉妒怨恨」的边界条款：先处理事实与边界，再处理情绪 |

## 四、跨同门混淆（同一份材料里的兄弟单元）

| 提问 | 容易混淆 | 正确判断 |
|---|---|---|
| 我看到一个便宜机会，但不在我熟悉的行业里。 | 少数机会下重注 vs 能力圈 | 应选能力圈（不在圈内不下注），而非下重注 |
| 我总觉得自己判断没问题，但结果总是差一点。 | 多元思维模型 vs 逆向排除 | 若症状是"只看一个角度"，选多元模型；若症状是"太自信"，选逆向排除 |
