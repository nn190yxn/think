## 二、可确认为原文的（逐字，注明篇名）

- "兵者，国之大事，死生之地，存亡之道，不可不察也。"（计篇）
- "兵者，诡道也……攻其无备，出其不意。"（计篇）
- "是故百战百胜，非善之善者也；不战而屈人之兵，善之善者也。"（谋攻篇）
- "知彼知己，百战不殆。"（谋攻篇）
- "胜兵先胜而后求战，败兵先战而后求胜。"（形篇）
- "凡战者，以正合，以奇胜。"（势篇）
- "激水之疾，至于漂石者，势也；鸷鸟之疾，至于毁折者，节也。故善战者，其势险，其节短。"（势篇）
- "故善战者，求之于势，不责于人，故能择人而任势。"（势篇）
- "凡先处战地而待敌者佚，后处战地而趋战者劳。故善战者，致人而不致于人。"（虚实篇）
- "故形人而我无形，则我专而敌分。"（虚实篇）
- "夫兵形象水……水之形避高而趋下，兵之形避实而击虚。"（虚实篇）
- "军争之难者，以迂为直，以患为利。"（军争篇）
- "三军可夺气，将军可夺心。"（军争篇）
- "兵贵胜，不贵久。"（作战篇）
- "主不可以怒而兴师，将不可以愠而致战。"（火攻篇）
- "投之亡地然后存，陷之死地然后生。"（九地篇）
- "无恃其不来，恃吾有以待也；无恃其不攻，恃吾有所不可攻也。"（九变篇）
- "兵者，国之大事"五事七计段：一曰道，二曰天，三曰地，四曰将，五曰法；将者，智、信、仁、勇、严也。（计篇）
