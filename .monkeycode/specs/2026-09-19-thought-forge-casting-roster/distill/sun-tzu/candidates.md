# 阶段 1：五路提取候选池（孙子）

## 一、框架提取

| 候选 | 要点 | 出处 |
|---|---|---|
| 五事七计 | 道天地将法 + 七个比较维度，庙算清单 | 计篇 |
| 先胜后战 | 先立于不败，再求敌之可败 | 形篇 |
| 奇正相生 | 以正合、以奇胜，变化无穷 | 势篇 |
| 虚实 | 避实击虚，我专而敌分 | 虚实篇 |
| 任势 | 求之于势，不责于人；择人而任势 | 势篇 |
| 全胜 | 不战而屈人之兵 | 谋攻篇 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 慎战 | 非利不动，非得不用，非危不战 |
| 知彼知己 | 信息是决策前提 |
| 致人而不致于人 | 掌握主动，不被调动 |
| 兵贵胜不贵久 | 成本约束高于形式上的持久 |
| 以迂为直，以患为利 | 绕路往往是捷径 |
| 主不可以怒而兴师 | 情绪不得进入决策 |
| 无恃其不来 | 不赌对方不来，靠自己的准备 |

## 三、案例提取

| 候选 | 内容 | 出处 |
|---|---|---|
| 以镒称铢 | 胜兵像用镒称铢，力量对比悬殊才动手 | 形篇 |
| 转圆石于千仞之山 | 势的意象：位置决定了力量效率 | 势篇 |
| 以碫投卵 | 虚实得当，攻击如同以石击卵 | 势篇 |
| 常山之蛇 | 首尾相应，整体协同（九地篇） | 九地篇 |
| 投之亡地然后存 | 死地反而激发求生 | 九地篇 |

## 四、反例提取

| 候选 | 内容 |
|---|---|
| 败兵先战而后求胜 | 先打了再想怎么赢 |
| 无所不备则无所不寡 | 处处设防等于处处薄弱 |
| 怒而兴师 | 因情绪开战，必后悔 |
| 百里而争利 | 长途奔袭争利，必损上将 |
| 穷寇勿迫 | 逼得太紧反而激起死战（边界提示） |

## 五、术语提取

五事、七计、庙算、先胜后战、奇正、虚实、任势、势险节短、全胜、诡道、九地、夺气夺心。
