# 阶段 4：选角测试用例（孙子）

## 一、该出手的

| 提问 | 期望选出的单元 |
|---|---|
| 对手在打价格战，我要不要跟着降。 | 慎战、以正合以奇胜 |
| 我想进入一个新市场，但对手已经很强。 | 知彼知己先胜后战、避实击虚我专而敌分 |
| 团队天天救火，永远被客户和对手牵着走。 | 致人而不致于人 |
| 这个项目已经拖了两年，还要不要继续投。 | 兵贵胜不贵久 |
| 我刚被对手激怒，想马上反击。 | 主不可以怒而兴师 |

## 二、不该出手的（诱饵）

| 提问 | 为什么不该由他出手 |
|---|---|
| 我们想和另一家公司共建一个生态，怎么谈。 | 共创型关系，他的框架预设敌我，适配很差（自己的盲点） |
| 帮我做一个三天的快速验证实验。 | 庙算与先胜的节奏偏慢，不适合小步快跑的场景 |
| 今天下午要不要开会。 | 常识级问题 |

## 三、边界模糊的

| 提问 | 判定要点 |
|---|---|
| 我该不该挖对手的核心员工。 | 该出手（知彼知己、以奇胜），但须提示：九地篇的"死地"手法在现代组织中会带来合规与声誉风险 |
| 我是不是该「不打就赢」，靠谈判解决。 | 该触发「不战而屈人之兵」，边界在于：谈判筹码仍来自自身的不可胜条件 |
| 竞争对手造谣，我要不要也放点料。 | 该触发「以正合以奇胜」，但必须提示边界：诡道部分被广泛误用为失信借口，现代场景中声誉成本远高于收益 |

## 四、跨同门混淆

| 提问 | 容易混淆 | 正确判断 |
|---|---|---|
| 我该不该现在动手，还是再等等。 | 慎战（道）vs 兵贵胜不贵久（法） | 判断"该不该打"选慎战；判断"拖延代价是否已过大"选不贵久 |
| 我该换掉这个负责人，还是改流程。 | 求之于势不责于人（势）vs 五事七计（器） | 判断责任归属选任势；判断开战前条件选五事七计 |
| 我的资源该怎么分配。 | 以正合以奇胜（术）vs 避实击虚（术） | 分配结构选奇正；选择突破点选虚实 |
