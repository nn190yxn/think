## 二、可确认为原著核心表述的

- 风会熄灭蜡烛，也会让森林大火烧得更旺。（他用来区分强韧与反脆弱的标志句）
- 脆弱系统在波动中毁灭，强韧系统在波动中生存，反脆弱系统在波动中成长。
- 杠铃策略：约 85%—90% 放在极度安全的一端，10%—15% 放在极高风险、极高回报的一端，**刻意放弃中间地带**。
- 可选择性：多做「损失有限、收益不封顶」的事。
- 否定法：与其寻找「什么让你幸福」，不如先排除「什么会让你痛苦」；与其找赢家，不如先排除输家。
- 黑天鹅三特征：极其罕见、影响巨大、事后看来又似乎可以解释。
- 不要试图预测风暴，而是建造一艘能乘风破浪的方舟。

## 三、标为「转述」或需注意的

- 「杀不死你的会让你更强大」在流传中被归给他，实为尼采式表述的转用，本包不据此立单元。
- 杠铃策略在中文语境里被本土化成「红利 + 科技」的轮动——中金财富明确指出这与设计初衷相去甚远：它**从来不是收益增强工具，而是生存优先的风险管理框架**。
- 反脆弱 ≠ 自找苦吃（见下条批评）。

## 四、核验记录
