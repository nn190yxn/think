# 阶段 1：五路提取候选池（塔勒布）

## 一、框架提取

| 候选 | 要点 | 出处 |
|---|---|---|
| 三元结构 | 脆弱 / 强韧 / 反脆弱 | 《反脆弱》 |
| 黑天鹅 | 罕见、冲击大、事后可解释 | 《黑天鹅》 |
| 杠铃策略 | 85—90% 极安全 + 10—15% 极激进，放弃中间 | 《反脆弱》 |
| 可选择性 | 损失有限、收益不封顶 | 《反脆弱》 |
| 否定法 | 先移除脆弱性，再谈增益 | 《反脆弱》 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 不要预测，建造方舟 | 把精力从预测转到结构 |
| 冗余不是浪费 | 买的是「不做决定」的权利 |
| 拒绝天真的干预 | 消除波动会制造更大脆弱 |
| 生存优先、收益其次 | 杠铃的存在目的是活下来 |
| 避免不可逆损失 | 高杠杆是典型负面黑天鹅 |
| 小错可承受、大错不可犯 | 破产成本必须优先排查 |
