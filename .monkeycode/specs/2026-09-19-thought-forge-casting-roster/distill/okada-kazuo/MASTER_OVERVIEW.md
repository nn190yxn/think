# 阶段 0：稻盛和夫的整体理解

## 一、这个人到底在教什么（主旨）

**经营的根本是把人的动机理正，再用数字让每个人看见自己的经营。**

稻盛的两条腿是"哲学"与"实学"：哲学解决"为什么做、以什么为判断基准"（作为人何谓正确）；实学解决"怎么让组织里每个人都在算自己的账"（阿米巴与单位时间核算、会计七原则）。他反复说：哲学不共有，阿米巴导入必失败。

## 二、骨架

1. **判断基准**——以"作为人，何谓正确"为准，以善恶而非得失作判断。
2. **人生方程式**——结果 = 思维方式 × 热情 × 能力；思维方式可取负值。
3. **六项精进**——个人层面的心力维持系统。
4. **经营十二条**——经营者的行动纲领，从目的意义到乐观态度。
5. **会计七原则**——用会计约束经营的自我欺骗（现金为本、一一对应、双重确认等）。
6. **阿米巴经营**——把组织切成能独立核算的小单元，用单位时间核算驱动全员参与。
7. **萧条对策**——把萧条当作成长机会，五条具体动作。

## 三、关键术语

| 术语 | 含义 |
|---|---|
| 作为人，何谓正确 | 一切判断的原点，超越得失 |
| 人生方程式 | 结果 = 思维方式 × 热情 × 能力 |
| 六项精进 | 努力、谦虚、反省、感谢、利他、不烦恼 |
| 阿米巴 | 能独立核算的最小经营单元 |
| 单位时间核算 | 用（收入 - 费用）÷ 总时间衡量小单元效益 |
| 会计七原则 | 现金为本、一一对应、筋肉坚实、完美主义、双重确认、提高核算效益、玻璃般透明 |
| 双重确认 | 不让人犯罪的制度设计：钱与票据分开、公章与保险箱两人共管 |
| 定价即经营 | 定价决定经营成败，定价与降本须联动 |
| 水库式经营 | 景气时蓄水，萧条时有储备 |

## 四、批判与盲点

1. **对人的要求极高**：全员参与经营依赖员工意愿与企业文化，多数公司只学到核算形式，学不到共有哲学。
2. **对高速变化的技术型市场着墨少**：方法优势在制造与实体经营，平台型竞争、快速试错的场景适配度低。
3. **核算的副作用**：小单元核算容易催生内部博弈、争夺定价与资源，反而损害整体。
4. **幸存者偏差**：稻盛本人的成功被广泛复盘，而照搬阿米巴失败的案例很少被同样认真地记录。
5. **强人格依赖**：方法高度依赖经营者本人的品格与持续宣讲，换人后能否延续是未解问题。

## 五、可应用场景

组织设计与考核、定价与成本决策、判断经营是否健康（现金流）、低谷期该做什么、以及个人层面的心性维持。
