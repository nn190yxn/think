# 阶段 4：选角测试用例（稻盛和夫）

## 一、该出手的

| 提问 | 期望选出的单元 |
|---|---|
| 公司账面有利润，但账上就是没钱，工资都快发不出了。 | 现金为本、一一对应 |
| 团队越来越大，我看不清每个环节到底赚不赚钱。 | 阿米巴与单位时间核算 |
| 这个产品该定多少钱，我拿不准，同行都比我们便宜。 | 定价即经营 |
| 大环境不好，订单掉了一半，我该先砍什么。 | 萧条是成长的机会、销售最大化经费最小化 |
| 员工总觉得在给老板打工，怎么让他们关心成本。 | 阿米巴与单位时间核算、双重确认 |

## 二、不该出手的（诱饵）

| 提问 | 为什么不该由他出手 |
|---|---|
| 帮我写一份融资 BP 的路演词。 | 属表达与融资技巧，他的方法集中在经营与人 |
| 我想做短视频账号，怎么快速起号。 | 增长与内容打法，不在他的框架内 |
| 明天面试穿什么。 | 常识级问题 |

## 三、边界模糊的

| 提问 | 判定要点 |
|---|---|
| 要不要用高薪挖一个同行的高手。 | 该出手，但要用「心性优先」与「作为人何谓正确」拷问动机与长期性，而非只算钱 |
| 员工犯了错，我要不要当场发火。 | 该触发「不要有感性的烦恼」；但须提示边界：先处理事实与责任，再处理情绪 |
| 公司要不要上市。 | 属资本结构选择，他的框架只提供判断基准（以善恶而非得失），不提供资本答案 |

## 四、跨同门混淆

| 提问 | 容易混淆 | 正确判断 |
|---|---|---|
| 我想让每个部门自己算账，但又怕他们互相抢资源。 | 阿米巴（术）vs 双重确认（器） | 组织切分选阿米巴；防内部舞弊选双重确认 |
| 我们该不该降价换销量。 | 定价即经营（术）vs 销售最大化经费最小化（法） | 定价决策选「定价即经营」；判断动作是增收还是增费选「销售最大化、经费最小化」 |
| 团队最近士气低，我该讲点什么。 | 六项精进（气）vs 以善恶而非得失（道） | 士气与心力问题选六项精进；是非取舍问题选判断基准 |
