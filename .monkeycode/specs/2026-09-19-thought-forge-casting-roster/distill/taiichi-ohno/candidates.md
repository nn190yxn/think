# 阶段 1：五路提取候选池（大野耐一）

## 一、框架提取

| 候选 | 要点 | 出处 |
|---|---|---|
| TPS 两大支柱 | 准时化 + 自働化 | 体系资料与播客 |
| 七大浪费 | 过量生产、等待、搬运、加工、库存、动作、缺陷 | 讲师教材 |
| 看板系统 | 后工序拉动前工序 | 现场笔记 |
| 标准作业 | 以人的动作为中心的当前最优 | 讲师教材 |
| 五个为什么 | 连问五次找根因 | 播客 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 目标是消除浪费不是降本提效 | 内核是价值判断 |
| 异常即停 | 绝不让不良品往下流 |
| 停线反而减少浪费 | 问题早暴露 |
| 没有标准就没有改善 | 标准是基准 |
| 现场才有真相 | 报表看不见细节 |
| 尊重一线判断 | 晚年只答两个字 |

## 三、案例提取

| 候选 | 内容 | 出处 |
|---|---|---|
| 丰田佐吉的自动织机 | 1924 年，断线自动停机 | 体系资料 |
| 美国超市补货 | 1956 年访美得到看板灵感 | 现场笔记 |
| 石油危机封神 | 1973 年 TPS 表现突出 | 播客 |
| 推行三十年 | 从机加工车间小实验到全公司 | 播客 |
| 大野晚年的回答 | 被问 TPS 本质，只答「尊重」 | 今日头条 |

## 四、反例提取

| 候选 | 内容 |
|---|---|
| 把工具当目的 | 90% 企业学丰田失败的根源 |
| 过量生产 | 掩盖故障与不良，制造虚假效率 |
| 只看报表不下现场 | 看不见真问题 |
| 自动化不带判断 | 机器无脑循环，带着错误生产 |
| 照搬无绝境条件 | 没有生存压力，改善推不动 |

## 五、术语提取

TPS、准时化（JIT）、自働化（Jidoka）、看板、七大浪费、过量生产、标准作业、节拍时间、一个流、五个为什么、安灯绳、停线权、改善（Kaizen）、精益生产。
