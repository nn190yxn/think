# 阶段 0：大野耐一的整体理解

## 一、主旨

**彻底消除不产生价值的动作；让异常当场暴露、当场停下；把判断权交回现场的人。**

大野耐一的东西看上去是"工具箱"（看板、5S、5Why、七大浪费），但它的内核是一次**价值判断的反转**：不是"怎么生产得更多"，而是"哪些动作根本不产生价值"。他还坚持另一件事：搞改善的人必须站在现场，而不是坐在办公室看报表。

## 二、骨架

1. **内核**：彻底消除一切不产生价值的浪费（TPS 的终极目标不是降本提效）。
2. **两大支柱**：准时化（拉动式生产）与自働化（异常即停）。
3. **自働化**：带人字旁的「働」——让机器具备人的判断力，异常自动停机。
4. **看板**：拉动生产的唯一指令，不是生产计划表。
5. **七大浪费**：过量生产是万恶之源，因为它掩盖其他问题。
6. **标准作业**：没有标准就没有改善；标准是改善的比较基准。
7. **五个为什么**：穿透表象找根本原因。
8. **尊重**：给一线停线权，承认现场判断比报表更接近真相。

## 三、关键术语

| 术语 | 含义 |
|---|---|
| 丰田生产方式（TPS） | 消除浪费的完整体系 |
| 准时化（JIT） | 按需要的时点、数量、品种生产 |
| 自働化（Jidoka） | 异常即停，不让不良品流出 |
| 看板 | 后工序拉动前工序的指令 |
| 七大浪费 | 过量生产、等待、搬运、加工、库存、动作、缺陷 |
| 标准作业 | 以人的动作为中心的当前最优作业方式 |
| 五个为什么 | 连问五次以上找根本原因 |
| 停线权 | 一线发现异常可停线 |
| 一个流 | 单件流动，不用批量掩盖问题 |

## 四、批判与盲点

1. **学不会的人远多于学会的**：全球 90% 以上企业学丰田失败，根源是把工具当目的。
2. **推行代价极大**：用了约 30 年，他被一线骂「地狱大野」、被管理层质疑；照搬者通常低估了这个代价。
3. **诞生条件特殊**：TPS 生于资源极度匮乏、资金链濒断的绝境，是一种被逼出来的生存方式。
4. **场景错配风险**：工具来自制造业现场；服务业与知识型工作照抄会走形（我们的判断）。
5. **人的压力问题**（我们的判断）：停线权与高强度改善文化之间如何平衡，材料里没有正面讨论，使用时需自行补上这条。

## 五、可应用场景

流程改善（找出并消除等待、返工、堆积）、现场管理、库存与交付周期问题，以及"为什么我们越忙越乱"的诊断。
