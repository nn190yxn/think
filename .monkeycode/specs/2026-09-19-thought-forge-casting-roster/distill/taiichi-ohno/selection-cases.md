# 阶段 4：选角测试用例（大野耐一）

## 一、该出手的

| 提问 | 期望选出的单元 |
|---|---|
| 我们车间总是堆一堆半成品，怎么办。 | 七大浪费检查表、准时化（拉动式） |
| 客户临时改单，我们就乱套。 | 准时化、看板是拉动指令 |
| 同一个质量问题改了好几次还是出。 | 七个为什么、别把工具当目的 |
| 我要不要上一套 5S 和看板。 | 别把工具当目的、七大浪费检查表 |
| 员工发现问题不敢停线。 | 自働化：异常即停、尊重：把判断权交回现场 |

## 二、不该出手的（诱饵）

| 提问 | 为什么不该由他出手 |
|---|---|
| 我该不该换供应商。 | 属商业关系判断 |
| 帮我算一下这批货的毛利。 | 算术题 |
| 明天穿什么。 | 常识级问题 |

## 三、边界模糊的

| 提问 | 判定要点 |
|---|---|
| 我在做线上服务业，能不能用丰田那套。 | **先说边界**：这套工具来自制造业现场，服务业与知识工作需重估（我们的判断）；该触发「七大浪费检查表」的可见部分，但不要照搬看板与节拍等硬工具 |
| 我们公司没有生存压力，改善推不动怎么办。 | 该触发「别把工具当目的」与道题：TPS 生于资源极度匮乏的绝境；没有外部压力时，要自己造出紧迫感（如缩短交付周期），而不是靠口号 |
| 我想停线整改，但老板要产量。 | 该触发「产量让位质量」与「自働化」，边界是：停线要有截止与升级机制，不能无限停 |

## 四、跨同门混淆

| 提问 | 容易混淆 | 正确判断 |
|---|---|---|
| 库存到底要不要留。 | 准时化（法）vs 七大浪费（器） | 判断拉动逻辑选前者；判断具体哪类浪费选后者 |
| 我要不要上自动化设备。 | 自働化（法）vs 别把工具当目的（势） | 判断"带不带判断力"选前者；判断"是不是在买工具交差"选后者 |
| 问题查到了但没人改。 | 七个为什么（术）vs 尊重（道） | 查根因用术；改不动往往是权责问题，用道 |
