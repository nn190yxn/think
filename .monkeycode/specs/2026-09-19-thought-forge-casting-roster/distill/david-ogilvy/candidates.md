# 阶段 1：五路提取候选池（奥格威）

## 一、框架提取

| 候选 | 要点 | 出处 |
|---|---|---|
| 十三条广告信条 | 推销优先、长期投资、说什么比怎么说重要 | 《一个广告人的自白》 |
| 广告本文十二原则 | 只讲事实、不用最高级、像私人谈话 | 同上 |
| 标题准则 | 五倍阅读率、八成广告费 | 同上 |
| 品牌形象论 | 广告是品牌的长期投资 | 20 世纪 60 年代中期 |
| copy platform | 明确传达商品功用的文案规范 | 信条之一 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 广告是推销技术不是艺术 | 对销售负责 |
| 只说事实 | 不用最高级，消费者会打折扣 |
| 承诺消费者利益 | 标题必须给好处 |
| 写得像私人谈话 | 不做散文腔 |
| 不做亵渎品牌印象的行为 | 每次投放都是投资或透支 |
| 底线：不骗人 | 不做好意思给家人看的广告 |

## 三、案例提取

| 候选 | 内容 | 出处 |
|---|---|---|
| 哈撒韦衬衫「戴眼罩的男人」 | 用穿衬衫的人界定品牌形象 | 广告史案例 |
| 不用最高级 | 消费者对"最"字会打折 | 本文原则 |
| 照片下加说明 | 多数读者只读图片说明 | 插图准则 |
| 长文案有效 | 不要怕写长的本文 | 本文原则 |
| 厨具推销员出身 | 上门推销的经历塑造了销售导向 | 生平 |

## 四、反例提取

| 候选 | 内容 |
|---|---|
| 自我陶醉式广告 | 为拿奖而做，不为卖货 |
| 攻击别家广告 | 信条明确禁止 |
| 用最高级形容词 | 消费者会打折扣 |
| 只有花样没有卖点 | 说什么比怎么说更重要 |
| 标题不承诺利益 | 等于浪费八成广告费 |

## 五、术语提取

推销技术、We sell or else、标题阅读率、事实型文案、私人谈话语气、品牌形象（BI）、copy platform、全垒打、图文配合、名人推荐、长期投资。
