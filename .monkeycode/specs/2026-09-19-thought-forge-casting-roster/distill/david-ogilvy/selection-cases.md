# 阶段 4：选角测试用例（奥格威）

## 一、该出手的

| 提问 | 期望选出的单元 |
|---|---|
| 我这条广告看着挺好，就是没效果。 | 说什么比怎么说更重要、标题决定八成效果 |
| 标题怎么写才能让人点开。 | 标题决定八成效果、只讲事实 |
| 文案要不要写得华丽一点。 | 写得像私人谈话、只讲事实 |
| 我们能不能用"全网最低价"这类说法。 | 只讲事实，不用最高级、绝不制作不愿让家人看的广告 |
| 要不要为了冲数据做一条擦边的。 | 绝不制作不愿让家人看的广告、每个广告都是品牌长期投资 |

## 二、不该出手的（诱饵）

| 提问 | 为什么不该由他出手 |
|---|---|
| 帮我看看这个定价合不合理。 | 属定价与结构问题（那是波特的场） |
| 这个季度投多少预算。 | 财务测算问题 |
| 明天穿什么。 | 常识级问题 |

## 三、边界模糊的

| 提问 | 判定要点 |
|---|---|
| 我在做短视频，这套还有用吗。 | **适用前提问题**：他的准则成型于大众媒体时代，需按当下条件重估（我们的判断）；标题承诺利益与只讲事实仍成立，具体媒介技巧要重写 |
| 我这条纯情绪向的内容数据很好，要不要改成讲事实。 | 边界：在纯情绪与社交驱动型品类里，表达方式本身可能就是内容；该触发「说什么比怎么说更重要」但允许表达即内容 |
| 用名人推荐算不算违规。 | 该触发「文案检查清单」，但需先按当地合规要求核对——这已与当年不同 |

## 四、跨同门混淆

| 提问 | 容易混淆 | 正确判断 |
|---|---|---|
| 文案没人看。 | 标题决定八成效果（术）vs 说什么比怎么说更重要（法） | 先看标题（术）；标题没问题再看卖点（法） |
| 这条会不会伤品牌。 | 品牌长期投资（道）vs 不愿让家人看（气） | 长期透支判断用道；底线问题用气 |
| 该不该大改这次投放。 | 先研究商品与竞品（势）vs 文案检查清单（器） | 没做功课先补功课（势）；功课做完用清单体检（器） |
