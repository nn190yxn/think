# 阶段 0：奥格威的整体理解

## 一、主旨

**广告是推销技术，不是艺术；说什么比怎么说更重要；每一分钱都要对销售负责。**

奥格威把广告从"创意表演"拉回到**销售工具**：先研究商品与消费者，再决定说什么；把最大的卖点放进标题；只讲事实；每一次投放都是品牌形象的长期投资。

## 二、骨架

1. **推销优先**：We sell, or else——不卖，就死。
2. **说什么 > 怎么说**：诉求内容比诉求技巧重要。
3. **只讲事实**：不用"最高级"这类会被打折扣的词。
4. **标题决定成败**：标题的阅读率约为正文的五倍；标题没写好等于浪费八成广告费。
5. **写得像私人谈话**：避免散文腔、比喻腔。
6. **品牌形象是长期投资**：每个广告都在往品牌账户里存钱或取钱。
7. **创意是及格线**：没有伟大创意的广告只是二流品。
8. **底线**：绝不制作不愿意让自己家人看的广告。

## 三、关键术语

| 术语 | 含义 |
|---|---|
| 推销技术 | 广告的本质定位 |
| We sell, or else | 对销售的最终负责 |
| 标题阅读率 | 标题的杠杆位置 |
| 事实型文案 | 只讲事实，不用最高级 |
| 私人谈话语气 | 文案的语感标准 |
| 品牌形象（BI） | 广告是品牌长期投资 |
| copy platform | 明确传达商品功用的文案规范 |
| 全垒打 | 不做小打小闹的投放 |

## 四、批判与盲点

1. **时代条件变了**（我们的判断）：他的准则成型于报纸、杂志、电视主导的时代；算法分发与短视频时代，注意力获取与效果衡量方式已大不相同。
2. **「说什么>怎么说」有适用边界**（我们的判断）：在纯情绪与社交驱动型品类里，表达方式本身可能构成内容。
3. **缺少系统性实证反驳**：本次检索未找到针对其准则的系统性实证研究，其结论主要来自实战经验而非对照实验。
4. **合规环境变化**（我们的判断）：名人推荐、比较广告等做法在不同地区的合规要求已与当年不同。
5. **个人审美偏好明显**：他明确反对自我陶醉式与奖杯导向的广告，这既是原则也是偏好。

## 五、可应用场景

写标题、写产品卖点、判断一条广告/一篇推广文问题出在哪，以及"要不要讲事实还是讲感觉"这类判断。
