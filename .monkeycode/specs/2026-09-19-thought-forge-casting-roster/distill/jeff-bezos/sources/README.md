## 三、标为「转述」的

- 飞轮效应：更低的价格 → 更多顾客 → 更多卖家 → 更丰富的选择 → 更多顾客，循环一旦启动会越转越快。
- 逆向工作法（Working Backwards）：从客户需求出发反向设计产品。
- 空椅子战术：会议中放一把空椅，代表「客户在场」。
- 双披萨团队：团队规模以两个披萨能喂饱为限。
- 遗憾最小化框架：用「80 岁时回看会不会后悔」来决策。
- Prime 的内部争议：2005 年推出时团队反对，他坚持「速度是新的便利」。

## 四、核验记录

2026-09-21：条目经全网检索核对，来源包括一篇战略梳理长文（含招股书原文引用）、三篇人物与理念解读、一档商业人物播客。

**批评与争议同时留存**（写入盲点与边界）：
1. **垄断争议**：庞大体量带来垄断争议，长期引发讨论。
2. **严苛企业文化**：常年引发讨论；他会直接打断汇报说「这是愚蠢的」「你是在浪费我的时间」——原文评述是「这种风格让很多人感到不适」。
3. **长期主义被误读**：原文明确指出「长期主义，不等于简单熬时间，不是盲目死扛」。
4. **我们的判断**：他的做法依赖资本市场的长期容忍与规模优势，小体量组织照搬「长期不盈利」会直接出局。
