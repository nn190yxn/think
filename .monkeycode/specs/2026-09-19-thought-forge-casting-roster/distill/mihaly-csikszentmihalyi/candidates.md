# 阶段 1：五路提取候选池（契克森米哈伊）

## 一、框架提取

| 候选 | 要点 | 出处 |
|---|---|---|
| 心流八要素 | 可完成的工作、全神贯注、明确目标、即时反馈、深入投入、掌控、忘我、时间感改变 | 《心流》 |
| 精神熵 | 意识失序是体验变差的根源 | 第一章 |
| 技能与挑战平衡 | 难度与能力匹配时最易进入心流 | 心流成因 |
| 享乐与乐趣 | 恢复平衡 vs 带来成长 | 第三章 |
| 自得其乐的性格 | 主动在行动中找机会 | 第四章 |

## 二、原则提取

| 候选 | 要点 |
|---|---|
| 幸福不可直接追求 | 越盯越得不到 |
| 注意力是稀有资源 | 意识处理能力极有限 |
| 目标与反馈要明确且即时 | 心流的可设计条件 |
| 改造环境 + 改造自己，两条都要 | 单独做任一条都不够 |
| 心流不是学习入口 | 学新能力靠难受到卡壳的练习 |
| 快乐来自主动参与 | 被动娱乐只给刺激不给满足 |

## 三、案例提取

| 候选 | 内容 | 出处 |
|---|---|---|
| 钢琴作曲家的原话 | 「我感觉不到自己……音乐自然而然从手中流泻而出」 | 中科院科普页 |
| 塞纳的摩纳哥赛道 | 「感觉不是我在开车」 | 播客转述 |
| 攀岩者、外科医生 | 高危与高难度活动中的心流 | 概念解读 |
| 看电视的低谷 | 闲暇看电视时注意力、清晰度、精力最低 | 概念解读 |
| 短视频时代 | 信息越多越难快乐，缺的是完整注意力 | 书评 |

## 四、反例提取

| 候选 | 内容 |
|---|---|
| 一味追求「爽感」 | 只求刺激，不产生成长 |
| 把心流当学习入门券 | 逃避必要的卡壳与犯错 |
| 只改造环境不改自己 | 换工作仍不快乐 |
| 目标模糊、反馈滞后 | 大公司常见的心流杀手 |
| 刷手机刷到麻木 | 刺激堆叠，注意力被切碎 |

## 五、术语提取

心流、最优体验、精神熵、意识秩序、注意力、技能与挑战平衡、即时反馈、自成目标、自得其乐的性格、享乐与乐趣、体验取样法。
