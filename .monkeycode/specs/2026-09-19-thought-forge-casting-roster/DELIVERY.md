## 一、这次交付了什么

一句话：**名册从 6 位大师扩到 20 位，而且每位都有六题（道法术气器势）的料；点将时能选人、能看到他会坐哪一题。**

具体是四块：

1. **20 位大师的名册**：每位九条可执行单元，每题（道法术气器势）都不缺，全部带触发条件、做法、原理、边界和出处。
2. **点将面板**：会诊前点「待选角」选人；能看到每位在各题的料有多少、本席位契合度、以及"他会坐哪一题"；选定后座位上留痕，可以取消或换人。
3. **六项体检的"去配置"**：设置页的体检清单，每一项现在都有按钮直接跳到该配置的地方（大师包在另一个境界，会直接带你过去）。
4. **修掉一处会骗人的地方**：点将面板预测"他会坐哪一题"的规则，原来跟内核真实选角有一处不一致（大师在该题完全没料时的回退），现已对齐并加了用例守住。
5. **诊断包导出**：设置页体检面板多一个「导出诊断包」按钮，把版本、体检结论、平台与采集开关、费用与备份份数写成一份 JSON 落在数据目录里；密钥只记「有没有写入」。
6. **修掉一个真机上才暴露的缺陷**：记录 id 靠「内容摘要 + 进程内计数器」生成，而计数器每次启动从 0 开始——重启后问同一个问题会算出同一个 id，报 `UNIQUE constraint failed`。现已混入时间片并加用例；这条是拿真库跑探针才撞出来的。

## 二、上手：从启动到第一场会诊

1. **打开软件**：启动后会自动建库、跑迁移，并**自动装入六个种子大师包**（已经装过就不重复装）。
2. **配一次模型**：进「我」→ 设置 → 「联网与模型平台」：打开联网，填服务地址与模型名，把密钥写进系统密钥库。
3. **体检过门槛**：同一页最上面的「体检清单」会告诉你差哪一项；每一项右边有「去配置」，点一下直接跳到要改的地方。四项必备全绿就能开跑。
4. **开一场会诊**：进「议」境界，写下你的问题（或从「观」里带一个进来）。
5. **点将**：看到「待选角」就点它，面板里挑人。挑不准就看两列——"这一题 N 条料"和"他会坐：某题"；确认入席后座位上会写「已点 · 姓名」。
6. **跑完看结果**：会诊结束会留下阵容与结论，可在「我」→ 历史回顾里回看。
